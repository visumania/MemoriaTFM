\section{Aplicación Web para la Visualización y Prueba del Modelo}
\label{ap:AplicacionWeb}

Como parte complementaria de este Trabajo de Fin de Máster, se ha desarrollado y desplegado una aplicación web interactiva que permite cargar uno de los modelos entrenados durante la fase de experimentación y utilizarlo para clasificar nuevas instancias de texto en tiempo real.

Debido a las limitaciones de memoria computacional de los entornos de despliegue gratuitos, no ha sido posible alojar el sistema \textit{Ensemble} multimodal al completo. En su lugar, se ha desplegado el modelo discriminativo textual \texttt{roberta-base}, el cual demostró una altísima capacidad de generalización para la detección de lenguaje sexista a lo largo de este proyecto.

Esta aplicación proporciona una interfaz gráfica sencilla e intuitiva para que cualquier usuario, incluyendo los miembros del tribunal, pueda interactuar con la inteligencia artificial desarrollada sin necesidad de conocimientos técnicos de programación o configuración de entornos.

\section*{Tecnologías Utilizadas}

El desarrollo y puesta en producción de la interfaz se ha llevado a cabo empleando el siguiente marco tecnológico:
\begin{itemize}
    \item \textbf{Backend e Inferencia:} \textit{Python} como lenguaje principal, utilizando la biblioteca \texttt{transformers} de \textit{Hugging Face} para la carga de los pesos del modelo y la tokenización del texto de entrada.
    \item \textbf{Frontend:} \texttt{Gradio}, un \textit{framework} de código abierto en Python que permite construir interfaces de usuario web (UI) orientadas específicamente a modelos de \textit{Machine Learning} de forma ágil.
    \item \textbf{Despliegue y Alojamiento:} La aplicación se encuentra contenerizada y alojada de forma pública y gratuita en la plataforma \textit{Hugging Face Spaces}.
\end{itemize}

\section*{Manual de Usuario}

El uso de la aplicación consta de un flujo extremadamente simplificado:
\begin{enumerate}
    \item Acceder a la URL indicada anteriormente.
    \item En el cuadro de texto principal, introducir la frase, comentario o transcripción que se desea someter a evaluación por parte del modelo.
    \item Pulsar el botón de envío (``\textit{Submit}'' o ``Clasificar'').
    \item Tras unos segundos de procesamiento (\textit{inferencia}), el sistema devolverá en el panel de salida la etiqueta predicha (``Sexista'' o ``No Sexista''), acompañada opcionalmente del porcentaje de confianza o probabilidad matemática calculada por la red neuronal.
\end{enumerate}

\section*{Ejemplo de uso}

A continuación, se detalla un caso de uso práctico simulando el comportamiento del sistema:

\bigskip
\noindent \textit{Texto introducido:} ``Deberías dejar de opinar de estas cosas y volver a fregar los platos.'' \\
\textit{Salida del modelo:} \texttt{Clase: Sexista (1) | Probabilidad: 98.4\%}

\bigskip
\noindent \textit{Texto introducido:} ``La brecha salarial es un problema que debemos combatir juntos.'' \\
\textit{Salida del modelo:} \texttt{Clase: No Sexista (0) | Probabilidad: 92.1\%}
